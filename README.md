## Road Lane Detection

The goal of this project is to detect road lanes in images, identify the lane in which the car is driving, and generate an alert when the car crosses a lane marking. The project uses computer vision techniques.

## Methods

- **K-Means Clustering** for road lane detection.
- **Hough Transform** for detecting lane lines.
- **Image Processing** for analyzing road images and identifying lane markings.
